\topic{Answering Multiple-Choice Questions}{}\label{sec:mc}

Most lost points came from multi-select questions: one option too many or one
too few. The knowledge was usually there; the checking procedure was not. The
same few traps appear again and again, so a fixed routine per option is worth
more than any single fact.

\sub{Four recurring traps}

\fig{%
\resizebox{\linewidth}{!}{%
\begin{tikzpicture}[
    pat/.style={draw=#1, fill=#1!8, rounded corners=4pt, thick, text width=3.35cm,
      minimum height=2.7cm, align=left, font=\sffamily\small, inner sep=6pt}]
  \node[pat=wrongc] (p1) at (0,0) {\textcolor{wrongc}{\textbf{Only one term}}\\[2pt]
    A risk computed from one product instead of the sum; a BPTT derivative along
    one path instead of all.};
  \node[pat=hookc, right=0.25cm of p1] (p2) {\textcolor{hookc}{\textbf{Absolute words}}\\[2pt]
    ``any function'', ``always the lowest MSE'', ``fewer steps'': one
    counterexample makes them false.};
  \node[pat=stepc, right=0.25cm of p2] (p3) {\textcolor{stepc}{\textbf{Half the question}}\\[2pt]
    ``true for CNNs \emph{but not} MLPs'' needs two checks. ``Underfitting'' is
    not ``overfitting''.};
  \node[pat=whyc, right=0.25cm of p3] (p4) {\textcolor{whyc}{\textbf{Missed a true option}}\\[2pt]
    The last pipeline step, a second task of a system, a textbook fact that
    looked too easy.};
\end{tikzpicture}}}{The four traps behind most lost points. The first costs
points in numeric tasks, the other three in multi-select tasks.}

\begin{steps}
\begin{enumerate}[leftmargin=*]
  \item \textbf{Judge every option on its own.} Cover the others and ask: ``Is
        this sentence true by itself?'' Never stop after the first true option,
        and never assume that exactly one or two options are correct.
  \item \textbf{Look for absolute words.} For ``always'', ``only'', ``any'',
        ``necessarily'', ``fewer'', ``lower'', search for one counterexample. One
        is enough to make the statement false.
  \item \textbf{Two-part questions.} ``True for A but not for B'' needs two checks
        per option: true for A? \emph{and} false for B?
  \item \textbf{Check for swapped partner concepts} (figure below). The trap is a
        true sentence with one word exchanged for its partner.
  \item \textbf{Check that the option answers the question.} ``Higher
        abstraction'' is a true property of CNNs, but not an effect of \emph{more
        filters in one layer}.
  \item \textbf{Numeric answers: formula first, numbers second.} Write the formula
        with its $\sum$ and count the terms before inserting numbers.
  \item \textbf{Sanity check the result.} A probability lies in $[0,1]$; a risk
        lies between the smallest and largest loss of that action; check the
        order of magnitude.
\end{enumerate}
\end{steps}

\topic{Vision Tasks and the Processing Chain}{}\label{sec:pipe}

A task is defined by what it outputs, and a pipeline stage by what goes in and
what comes out. Every error in this chapter disappears once the output type is
written down before choosing an answer.

\sub{Which tasks does a system solve?}

\begin{question}
Basketball software: bounding boxes around players, identifies name and number,
describes the action (dribbling, throwing, defense).
\end{question}
\begin{yours}
Only Action Recognition.
\end{yours}
\begin{correct}
Object Recognition \emph{and} Action Recognition.
\end{correct}

\begin{steps}
\begin{enumerate}[leftmargin=*]
  \item List every output the system produces: box, name/number, action.
  \item Map each output to a task with the table below.
  \item Tick \textbf{every} task that owns one of the outputs. A system usually
        combines several tasks.
\end{enumerate}
\centering\small
\begin{tabular}{@{}lll@{}}
  \toprule
  Output & Task & Here? \\
  \midrule
  one label for the whole image & object classification & \bad{} no \\
  box + \emph{which specific} player (name, number) & object recognition (identity) & \ok \\
  one class per pixel & semantic segmentation & \bad{} no pixel map \\
  verb over time (dribbling) & action recognition & \ok \\
  \bottomrule
\end{tabular}
\end{steps}

\begin{hook}
\textbf{Classification} $=$ which \emph{category} (``a player''). \textbf{Recognition}
$=$ which \emph{individual} (``player 23, Smith'').
\end{hook}

\sub{Order of the processing chain}

\begin{question}
Bring Data Preprocessing, Feature Selection, Feature Extraction, Feature
Preprocessing, Post processing, and Classifier into the correct order.
\end{question}

\begin{correct}
Data Preprocessing $\to$ Feature Extraction $\to$ Feature Selection $\to$
Feature Preprocessing $\to$ Classifier $\to$ Post processing.
\end{correct}

\begin{steps}
\begin{enumerate}[leftmargin=*]
  \item Write down input and output type of each stage (image, features, label).
  \item Chain them so that each output type is the next input type.
  \item Inside feature space: you can only \emph{select} features that have
        been \emph{extracted}; you normalize only the features that survive the
        selection, directly before the classifier.
\end{enumerate}
\end{steps}

\begin{hook}
\textbf{D}ata $\to$ \textbf{E}xtract $\to$ \textbf{S}elect $\to$
\textbf{P}repare $\to$ \textbf{C}lassify $\to$ \textbf{P}ost.
\end{hook}

\sub{Histogram matching is data preprocessing}

\begin{question}
Images taken under different illumination are transformed so that all
histograms have approximately the same distribution. Which pipeline stage is
this?
\end{question}

\begin{yours}
Feature preprocessing.
\end{yours}
\begin{correct}
Data preprocessing.
\end{correct}

\begin{why}
The method changes pixel values so that all images get a similar histogram.
Input: image. Output: image. That is the signature of data preprocessing
(pixel space). Feature preprocessing also ``normalizes'', but it acts on
\emph{feature vectors} after feature extraction, for example scaling each
feature to zero mean and unit variance. The word ``normalize'' is the trap; the
input/output type decides.
\end{why}

\begin{hook}
Ask: \emph{what comes out?} Image $\Rightarrow$ data preprocessing. Feature vector
$\Rightarrow$ extraction or feature preprocessing. Label $\Rightarrow$ classifier
or postprocessing.
\end{hook}

\sub{From classifier to detector: four steps}

\begin{question}
A classifier works for one fixed image resolution. Which steps turn it into an
object detector?
\end{question}
\begin{yours}
Sliding window, image pyramid, and boxes from scale and response were ticked;
non-maxima suppression was missed.
\end{yours}

\topic{Histograms, Entropy, and Saliency}{}\label{sec:sal}

Entropy is computed from the histogram alone, and the histogram forgets where
the pixels are. Both mistakes in this chapter come from forgetting one of these
two facts: either the spatial arrangement was taken into account where it does
not matter, or saliency was reduced to entropy where scale does matter.

\sub{Matching histograms and entropy values}

\begin{question}
Four black-and-white patches: assign each its histogram and its entropy value.
\end{question}
\begin{yours}
One pair was swapped: two patches with mirrored histograms (mostly white vs.\
mostly black) were exchanged.
\end{yours}

\begin{steps}
\begin{enumerate}[leftmargin=*]
  \item \textbf{Fix the axis orientation first.} The single-bar histogram must
        belong to the all-white patch a. Its bar sits on the right, so the axis
        runs from black (left) to white (right).
  \item For each patch, estimate the black/white fraction and pick the
        histogram with those bar heights. Mostly white (b): tall bar right.
        Mostly black (d): tall bar left.
  \item Compute $H = -\sum_i p_i\log_2 p_i$: one value $\Rightarrow 0$; $50/50
        \Rightarrow 1$; $25/75 \Rightarrow 0.81$.
  \item The two ``$0.8$'' tokens look identical but may be graded as distinct
        items. Place each next to the histogram it belongs to.
\end{enumerate}
\end{steps}

\sub{Swapping two grey values keeps the entropy}

\begin{question}
Which statements about entropy are true? (Uniform histogram, swapping two
colors, permuting pixels, homogeneous patch vs.\ edge.)
\end{question}
\begin{yours}
Only ``uniform histogram $\Rightarrow$ highest entropy'' was ticked; ``swapping
two colors does not change the entropy'' was missed.
\end{yours}

\sub{Most salient patch after Kadir et al.}

\begin{question}
Which of the four patches above is the most salient after Kadir and Brady?
\end{question}
\begin{yours}
Patch c, the checkerboard, because it has the highest entropy.
\end{yours}
\begin{correct}
Patch b, the black disk.
\end{correct}

\begin{why}
Kadir--Brady saliency is \textbf{not} entropy alone:
\[
y(s_p,x) = H_D(s_p,x)\cdot W_D(s_p,x),
\qquad
W_D(s,x) = s\!\int\Big|\tfrac{\partial}{\partial s}p(I,s,x)\Big|\,\mathrm{d}I .
\]
$H_D$ is taken at a scale $s_p$ where the entropy has a \textbf{peak} over scale,
and $W_D$ is large only if the histogram \textbf{changes across scale}. A patch
whose statistics look the same at every window size scores zero, however high
its entropy.
\end{why}

\sub{Gradient correlation and the correlation theorem}

\begin{question}
Instead of R-tables, correlate the complex gradient images
$I' = \partial_x I + i\,\partial_y I$ and $O' = \partial_x O + i\,\partial_y O$.
Which statements are true about $\operatorname{Re}/\operatorname{Im}(I'\star O')$
and about computing $I'\star O'$ with the DFT?
\end{question}
\begin{yours}
The real part was chosen correctly, but also
$I'\star O' = \mathrm{DFT}^{-1}\bigl(\mathrm{DFT}(I)\cdot\mathrm{DFT}(O)\bigr)$,
which has no conjugate and therefore computes a convolution.
\end{yours}
\begin{correct}
$\operatorname{Re}(I'\star O')$ sums the gradient dot products (almost Hough
voting), and
$I'\star O' = \mathrm{DFT}^{-1}\bigl(\mathrm{DFT}(I)\cdot\mathrm{DFT}(O)^*\bigr)$.
\end{correct}

\begin{center}\small
\begin{tabular}{@{}ll@{}}
  \toprule
  Frequency-domain product & Signal-domain result \\
  \midrule
  $\mathrm{DFT}(f)\cdot\mathrm{DFT}(g)$ & convolution $f*g$ \\
  $\mathrm{DFT}(f)\cdot\mathrm{DFT}(g)^*$ or $\mathrm{DFT}(f)^*\cdot\mathrm{DFT}(g)$ & correlation (the two only mirror the shift) \\
  $\mathrm{DFT}(f)^*\cdot\mathrm{DFT}(g)^*$ & neither \\
  \bottomrule
\end{tabular}
\end{center}

\begin{why}
Correlation slides the template \emph{without flipping} it; convolution flips it.
In the frequency domain, flipping a real signal is complex conjugation. The
conjugate undoes the flip that convolution would apply, so exactly one conjugate
turns a convolution into a correlation. For the real part: with
$a=a_x+ia_y$, $b=b_x+ib_y$, $\operatorname{Re}(a^*b)=a_xb_x+a_yb_y$, the dot
product of the two gradient vectors. The imaginary part is a cross product.
\end{why}

\begin{hook}
\textbf{Conv} $=$ plain product. \textbf{Corr} $=$ product with \textbf{one star}.
\end{hook}

\topic{Bayesian Decision Theory}{}\label{sec:bayes}

Every task in this chapter is a sum or a ranking. Posteriors and risks are sums
over \emph{all} hypotheses or states; discriminant functions only need to rank
the classes like the posterior; the expected error integrates $x$ away. The
mistakes came from dropping terms from a sum and from overlooking standard
facts about Gaussian classes.

\sub{Computing a posterior}

\begin{question}
$P(D\mid\Omega_1)=0.52$, $P(D\mid\Omega_2)=0.58$, $P(\Omega_1)=0.53$,
$P(\Omega_2)=0.47$. Find $P(\Omega_1\mid D)$ to four decimals.
\end{question}
\begin{correct}
$0.5027$
\end{correct}

\begin{steps}
\begin{enumerate}[leftmargin=*]
  \item Numerator per hypothesis: likelihood $\times$ prior.
  \item Evidence: sum of \emph{all} numerators.
  \item Posterior: own numerator $/$ evidence. Check that all posteriors sum to 1
        ($0.5027 + 0.4973$).
  \item Keep four or more decimals in between; round only at the end.
\end{enumerate}
\end{steps}

\sub{Expected risk of an action}

\begin{question}
Loss $\lambda(\alpha_i\mid\omega_j)$: treat ($\alpha_1$) costs 18 if ill
($\omega_1$) and 27 if healthy ($\omega_2$). $P(\omega_1\mid x)=0.75$. Expected risk
of treating?
\end{question}
\begin{yours}
$6.75 = 27\cdot0.25$: only the ``healthy'' term.
\end{yours}
\begin{correct}
$R(\alpha_1\mid x) = 18\cdot0.75+27\cdot0.25 = 13.50+6.75 = 20.25$
\end{correct}

\end{tikzpicture}}{The risk of one action is a sum over \emph{all} true states.

\begin{steps}
\begin{enumerate}[leftmargin=*]
  \item Fix the action: $\alpha_1$ (treat) $=$ one column of the loss table.
  \item Write one term per true state: $R(\alpha_1\mid x)=\lambda(\alpha_1\mid\omega_1)P(\omega_1\mid x)+\lambda(\alpha_1\mid\omega_2)P(\omega_2\mid x)$.
  \item Complete the posteriors: $P(\omega_2\mid x)=1-0.75=0.25$.
  \item Insert: $18\cdot0.75+27\cdot0.25=20.25$.
  \item \textbf{Sanity check:} the risk is a weighted average of the column
        entries, so it lies between 18 and 27.
  \item If asked for the decision: $R(\alpha_2\mid x)=57\cdot0.75+0\cdot0.25=42.75$
        $>20.25$ $\Rightarrow$ treat.
\end{enumerate}
\end{steps}

\begin{hook}
Risk $=$ \textbf{weighted average} of one action's losses. It can never be
smaller than the smallest loss in that column.
\end{hook}

\sub{Valid discriminant functions}

\begin{question}
Which of the following are valid discriminant functions $g_i(x)$ for the MAP
rule? Candidates included $P(\omega_i)$, $\sqrt{p(x\mid\omega_i)P(\omega_i)}$,
and $P(\omega_i\mid x)$.
\end{question}
\begin{yours}
$P(\omega_i)$ and $\sqrt{p(x\mid\omega_i)P(\omega_i)}$: the prior alone was
accepted, and the posterior itself was missed.
\end{yours}
\begin{correct}
$\sqrt{p(x\mid\omega_i)P(\omega_i)}$ and $P(\omega_i\mid x)$.
\end{correct}

\begin{why}
$g_i(x)$ is a valid discriminant function if it \textbf{ranks the classes like
the posterior} $P(\omega_i\mid x)$ for \textbf{every} $x$. The posterior itself
qualifies trivially, and so does any strictly increasing transform applied equally
to all classes. $P(\omega_i)$ ignores $x$: it picks the same class for every input.
\end{why}

\sub{Gaussian classes: shape of the decision boundary}

\begin{question}
Which statements about Gaussian class-conditional densities are true? (The four
statements are listed in the table.)
\end{question}
\begin{yours}
Only the last statement was ticked; the two standard facts about linear and
quadric boundaries were missed.
\end{yours}

\begin{why}
The key is one picture: \textbf{the logarithm of a Gaussian is a downward
parabola}, $\ln p(x\mid\omega_i) = -\frac{(x-\mu_i)^2}{2\sigma_i^2} + \text{const}_i$.
The width $\sigma_i$ sets how sharply the parabola bends. The decision boundary
is where two such parabolas (plus $\ln P(\omega_i)$) are equal, i.e.\ where their
\emph{difference} is zero. Two parabolas with the \textbf{same bend} differ by a
straight line: the $x^2$ terms cancel, one crossing. Two parabolas with
\textbf{different bends} differ by another parabola: the $x^2$ term survives, up
to two crossings.
\end{why}

  \item Expand the quadratic form:
        $g_i(x) = \underbrace{-\tfrac12 x^\top\Sigma_i^{-1}x}_{\text{quadratic}}
        + \underbrace{\mu_i^\top\Sigma_i^{-1}x}_{\text{linear}} + \text{const}_i$.
  \item Boundary: $g_1(x)-g_2(x)=0$. The quadratic part of the difference is
        $-\tfrac12 x^\top(\Sigma_1^{-1}-\Sigma_2^{-1})x$.
  \item $\Sigma_1=\Sigma_2$ $\Rightarrow$ it vanishes $\Rightarrow$ the boundary is
        $w^\top x + w_0 = 0$: a \textbf{hyperplane} (line in 2D, point in 1D).
  \item $\Sigma_1\ne\Sigma_2$ $\Rightarrow$ it stays $\Rightarrow$ the boundary is a
        \textbf{hyperquadric}. Which one depends on the sign pattern of
        $\Sigma_1^{-1}-\Sigma_2^{-1}$: all same sign (one class narrower in every
        direction) $\to$ ellipse; mixed signs (each class wider in some
        direction) $\to$ hyperbola; zero in one direction $\to$ parabola.
  \item Priors only change the constant $w_0$: they \emph{shift} the boundary
        toward the less probable class, never change its shape.
\end{enumerate}
\end{steps}

\begin{tabularx}{\linewidth}{@{}>{\raggedright\arraybackslash}p{5.2cm}c X@{}}
  \toprule
  Statement & True? & Reason \\
  \midrule

    $x^\top\Sigma^{-1}x$ is the same for every class and cancels \\
  arbitrary $\Sigma_i$ $\Rightarrow$ hyperquadric & \ok & quadratic term
    stays; ellipse, parabola, hyperbola \\
  same $\mu$, different $\Sigma_i$ $\Rightarrow$ $g_i=P(\omega_i)$ valid & \bad &

  same $\mu$ \emph{and} $\Sigma$, $P(\omega_2)>P(\omega_1)$ $\Rightarrow$

  \bottomrule
\end{tabularx}
\end{center}

\begin{hook}
\textbf{Shared} covariance $\to$ \textbf{straight} line. \textbf{Own} covariance
$\to$ \textbf{curve}. Only \textbf{identical} likelihoods let the prior decide
alone.
\end{hook}

\sub{Expected classification error}

\begin{question}
Binary MAP classification. Which expressions give the expected classification
error, in general and if $P(\omega_1\mid x)>P(\omega_2\mid x)$ for all $x$?
\end{question}
\begin{yours}
The general $\min$-integral was correct, but for the special case
$P(\omega_2\mid x)$ was chosen, which still depends on $x$.
\end{yours}
\begin{correct}
$P(\text{error})=\int\min[P(\omega_1\mid x),P(\omega_2\mid x)]\,p(x)\,dx$,
and in the special case $P(\text{error})=P(\omega_2)$.
\end{correct}

\begin{steps}
\begin{enumerate}[leftmargin=*]
  \item If $P(\omega_1\mid x)>P(\omega_2\mid x)$ for every $x$, the classifier
        always says $\omega_1$.
  \item It is wrong exactly when the truth is $\omega_2$. Error at $x$:
        $P(\omega_2\mid x)$.
  \item \emph{Expected} error averages over all $x$:
        $\int P(\omega_2\mid x)\,p(x)\,dx = P(\omega_2)$ (marginalization).
  \item $P(\omega_2\mid x)$ alone is the error at \emph{one} $x$; an expected value
        cannot still contain $x$.
\end{enumerate}
\end{steps}

\begin{hook}
``Expected'' means the $x$ is integrated out. If $x$ is still in the answer, it is
not an expectation.
\end{hook}

\topic{Parameter Estimation}{}\label{sec:mle}

Maximum likelihood always follows the same four steps, and the result must be
the \emph{parameter}, not a statistic of the data. Judging estimators needs one
formula: mean squared error equals squared bias plus variance.

\sub{Maximum likelihood: always the same recipe}

The first task (Poisson) was left blank; the second (geometric) returned the
sample mean instead of the parameter. Both follow the same four steps.

\begin{question}
Error counts $X=\{2,8,4,2,6\}$, model $P(k)=\lambda^k e^{-\lambda}/k!$.
Find $\lambda_\text{MLE}$.
\end{question}
\begin{correct}
$\lambda_\text{MLE} = \bar{k} = 22/5 = 4.40$
\end{correct}

\begin{steps}
\begin{enumerate}[leftmargin=*]
  \item Likelihood (product over samples):
        $L(\lambda) = \prod_i \lambda^{k_i}e^{-\lambda}/k_i!$
  \item Log-likelihood: $\ell(\lambda) = \big(\sum_i k_i\big)\ln\lambda - n\lambda
        - \sum_i\ln k_i!$
  \item Derivative $=0$: $\frac{\sum_i k_i}{\lambda} - n = 0$
        $\;\Rightarrow\; \lambda_\text{MLE} = \frac1n\sum_i k_i$
  \item Insert: $(2+8+4+2+6)/5 = 22/5 = 4.40$
\end{enumerate}
\end{steps}

\begin{yours}
7.4: the sample mean, not the parameter.

\begin{correct}
$p_\text{MLE} = 5/37 \approx 0.14$
\end{correct}

\begin{steps}
\begin{enumerate}[leftmargin=*]
  \item Likelihood: $L(p)=\prod_i (1-p)^{k_i-1}p$.
  \item Log-likelihood: $\ell(p)=\sum_i(k_i-1)\ln(1-p)+n\ln p$, with
        $\sum_i(k_i-1)=37-5=32$, $n=5$.
  \item Derivative $=0$: $-\dfrac{32}{1-p}+\dfrac{5}{p}=0
        \;\Rightarrow\; 5(1-p)=32p \;\Rightarrow\; p=\dfrac{5}{37}$.
  \item General form: $p_\text{MLE}=\dfrac{n}{\sum_i k_i}=\dfrac{1}{\bar k}$.
        Insert: $1/7.4 = 0.135 \to 0.14$.
  \item \textbf{Sanity check:} $p$ is a probability. Any answer outside $[0,1]$ is
        wrong.
\end{enumerate}
\end{steps}

  Bernoulli & success probability & fraction of ones \\
  Gaussian & $\mu$ & $\bar x$ \\
  Gaussian & $\sigma^2$ & $\frac1n\sum_i(x_i-\hat\mu)^2$ (divide by $n$) \\
  Geometric $(1-p)^{k-1}p$ & per-trial probability & $1/\bar k$ \\
  Exponential $\lambda e^{-\lambda t}$ & rate & $1/\bar t$ \\
  \bottomrule
\end{tabular}
\end{center}

\begin{hook}
\textbf{Counts} $\to$ mean. \textbf{Waiting times} $\to$ one over the mean.
\end{hook}

\sub{Which functions have the same maximizer as the likelihood?}

\begin{question}
Poisson counts $k_1,\dots,k_n$. Which functions have their extremum at
$\lambda_\text{MLE}$?\\[2pt]
$L_1=e^{-n\lambda}\prod_i\frac{\lambda^{k_i}}{k_i!}$,\quad
$L_2=\prod_i\frac{\lambda^{k_i}}{k_i!}$,\quad
$L_3=-n\lambda+\log\lambda\sum_ik_i$,\quad
$L_4=-n\lambda-\sum_i\log k_i!+\log\lambda\sum_ik_i$
\end{question}
\begin{yours}
$L_1$ and $L_4$ ticked, $L_3$ missed.
\end{yours}
\begin{correct}
$L_1$, $L_3$, $L_4$.
\end{correct}

\begin{why}
The maximizer $\arg\max_\lambda$ only cares about the \emph{shape} of the
function in $\lambda$. Three operations never move it:
\begin{itemize}[leftmargin=*]
  \item a strictly increasing transformation ($\log$, $\exp$, $\sqrt{\cdot}$);
  \item adding or dropping a term that does not contain $\lambda$;
  \item multiplying by a positive constant that does not contain $\lambda$.
\end{itemize}
Anything that removes or changes a $\lambda$-dependent part does move it.
\end{why}

\begin{steps}
\begin{enumerate}[leftmargin=*]
  \item Write the true likelihood: $L(\lambda)=\prod_i\lambda^{k_i}e^{-\lambda}/k_i!
        =e^{-n\lambda}\prod_i\lambda^{k_i}/k_i!$. This is exactly $L_1$. \ok
  \item Take the log: $\ell=-n\lambda+\log\lambda\sum_ik_i-\sum_i\log k_i!$. This
        is $L_4$. \ok
  \item $L_3=L_4+\sum_i\log k_i!$. The added term is a constant in $\lambda$. \ok
  \item $L_2=L_1\cdot e^{n\lambda}$. The factor depends on $\lambda$, so the shape
        changes: $L_2$ grows without bound, no maximum at $\bar k$. \bad
  \item Cross-check by differentiating the log-forms: $L_3'=L_4'=-n+\sum_ik_i/\lambda$,
        zero at $\bar k$. Same derivative $\Rightarrow$ same extremum.
\end{enumerate}
\end{steps}

\begin{hook}
For every candidate ask: \textbf{what differs from $L$ or $\log L$?} A constant
in $\lambda$ $\to$ same maximizer. Something with $\lambda$ in it $\to$ different.
\end{hook}

\sub{Bias, variance, and MSE of estimators}

\begin{question}
$X_i\sim\mathcal N(\mu,\sigma^2)$. Estimators $\hat\mu_A=0$,
$\hat\mu_B=\frac1N\sum_iX_i$, $\hat\mu_C=X_1$. Which has the highest / lowest
variance, and does $\hat\mu_B$ always have the lowest MSE?
\end{question}
\begin{yours}
``$\hat\mu_B$ \emph{always} has the lowest MSE'' was ticked. The two variance
statements were correct.
\end{yours}

\sub{Comparing two estimators by bias and variance}

\begin{question}
Two estimators $\hat f_1,\hat f_2$. Which statements are true?
(a) Equal bias, $\mathrm{Var}(\hat f_1)>\mathrm{Var}(\hat f_2)=1$ $\Rightarrow$
$\hat f_1$ better.
(b) $\hat f_1$ lower bias and lower variance $\Rightarrow$ $\hat f_2$ better.
(c) $\hat f_1$ higher bias and higher variance $\Rightarrow$ $\hat f_2$ better.
(d) Bias $1$, Var $5$ for $\hat f_1$; bias $2$, Var $1$ for $\hat f_2$
$\Rightarrow$ $\hat f_2$ better.
\end{question}
\begin{yours}
Only (c) ticked; (d) missed. Lower bias looked like the deciding advantage of
$\hat f_1$.
\end{yours}
\begin{correct}
(c) and (d).
\end{correct}

\begin{steps}
\begin{enumerate}[leftmargin=*]
  \item ``Better'' means \textbf{lower MSE}. Write
        $\mathrm{MSE}=\mathrm{Bias}^2+\mathrm{Var}$ before looking at the options.
  \item \textbf{Dominance cases} (one estimator at least as good in both terms):
        decide without numbers. (a) equal bias, larger variance $\Rightarrow$
        $\hat f_1$ \emph{worse} \bad. (b) $\hat f_1$ better in both $\Rightarrow$
        $\hat f_1$ better \bad. (c) $\hat f_2$ better in both \ok.
  \item \textbf{Trade-off cases} (one better in bias, the other in variance):
        always compute. (d) $1^2+5=6$ versus $2^2+1=5$ $\Rightarrow$ $\hat f_2$
        better \ok.
  \item Square the bias. Without squaring, (d) would give $6$ vs.\ $3$: same
        verdict here, but not in general (bias $3$, Var $0$: MSE $9$, not $3$).
\end{enumerate}
\end{steps}

Neither lower bias nor lower variance alone makes an estimator better. If
neither estimator dominates, \textbf{compute $\mathrm{Bias}^2+\mathrm{Var}$}.
\end{hook}

\topic{Training Neural Networks}{}\label{sec:nn}

This chapter follows one training step: what backpropagation stores and passes
on, how the loss shapes the gradient, why SGD is used, and how to read and fix

otherwise correct answers, so the tables list a verdict and a one-line reason

\sub{Memory consumption of backpropagation}

\begin{yours}
``Memory is proportional to the number of trainable parameters.''
\end{yours}
\begin{correct}
``Memory is proportional to the combined output dimensionalities of the nodes in
the network.''
\end{correct}

\begin{why}
The backward pass needs, at every node, the value that node produced in the
forward pass: the input $x$ for the derivative of $w\cdot x$, the ReLU input to
know whether it was active. All these \textbf{activations} are stored until the
backward pass. Their number is the sum of the output sizes of all nodes (times the
batch size). Convolutional layers have few parameters but huge outputs, so
parameter count and memory are not proportional.
\end{why}

\end{hook}

\begin{hook}
Underfitting $=$ too \textbf{little capacity}: add units (wider) or layers
(deeper). ``More data'' is the cure for the \emph{other} problem.
\end{hook}

\topic{Convolutional Networks}{}\label{sec:cnn}

A convolutional layer is defined by its kernel tensor: kernel size, input
channels, output channels. Parameter counts, width versus depth, and the
comparison with MLPs all follow from this tensor; pooling adds invariance on
top.

\sub{Number of weights}

\begin{question}
A $3\times3$ convolution maps a $32\times32\times12$ input to a
$16\times16\times28$ output. How many weights (without biases)?
\end{question}
\begin{yours}
$252 = 3\cdot3\cdot28$: the input channels were forgotten.
\end{yours}
\begin{correct}
$3\cdot3\cdot12\cdot28 = 3024$
\end{correct}

\begin{tikzpicture}[x={(1cm,0)}, y={(0,1cm)}]

  \cuboid{5.2}{1.1}{0.6}{0.6}{1.3}{hookc}
  \node[font=\sffamily\small, align=center] at (5.9,-0.55) {one filter\\$3\times3\times\mathbf{12}$};
  \node[font=\sffamily\bfseries, text=hookc] at (7.3,1.8) {$\times\,28$};

\begin{steps}
\[
\#\text{weights} = K_h\cdot K_w\cdot C_\text{in}\cdot C_\text{out}
 = 3\cdot3\cdot12\cdot28 = 3024,
\qquad \#\text{biases} = C_\text{out} = 28 .
\]
Stride: $W_\text{out} = \left\lfloor \frac{W_\text{in}+2P-K}{S}\right\rfloor + 1$.
Halving the size ($148\to74$ with $K=3$, $P=1$) means $S=2$.
\end{steps}

\sub{More filters in one layer}

\begin{yours}
``Higher abstraction capabilities of the layer'' was ticked as an effect of
adding filters.
\end{yours}
\begin{correct}
Increase in output dimensionality; increased number of features the layer can
respond to.
\end{correct}

  \toprule

  \midrule

    at the same level & \bad \\
  More layers (\textbf{depth}) & larger receptive field, features of features & \ok \\
  \bottomrule
\end{tabular}
\end{center}

\topic{Recurrent Networks}{}\label{sec:rnn}

Backpropagation through time is ordinary backpropagation on the unrolled
network. The only question is how many paths lead from the output to the
variable of interest: an input enters at one time step, the shared weight at
every time step.

\sub{Derivative with respect to an input}

This task was left blank.

\begin{question}
RNN cell $h_t = a\,h_{t-1} + a\,x_t$ with $a=1$, $h_0=0$, sequence
$(x_1,x_2,x_3)=(1,4,5)$. What is the derivative with respect to $x_1$?
\end{question}
\begin{correct}
$\partial h_3/\partial x_1 = a^3 = 1$
\end{correct}

\fig{%
\begin{tikzpicture}[
    cell/.style={draw=accent, fill=accent!8, rounded corners=3pt, thick,
      minimum width=1.5cm, minimum height=0.9cm, font=\sffamily},
    inp/.style={font=\sffamily},
    fwd/.style={-{Latex[length=2.2mm]}, thick, black!60},
    bwd/.style={-{Latex[length=2.2mm]}, thick, wrongc, dashed}]
  \node[inp] (h0) at (0,0) {$h_0=0$};
  \node[cell] (h1) at (2.8,0) {$h_1$};
  \node[cell] (h2) at (5.6,0) {$h_2$};
  \node[cell] (h3) at (8.4,0) {$h_3$};
  \node[inp] (x1) at (2.8,-1.9) {$x_1=1$};
  \node[inp] (x2) at (5.6,-1.9) {$x_2=4$};
  \node[inp] (x3) at (8.4,-1.9) {$x_3=5$};
  \draw[fwd] (h0) -- node[below, font=\small] {$\cdot a$} (h1);
  \draw[fwd] (h1) -- node[below, font=\small] {$\cdot a$} (h2);
  \draw[fwd] (h2) -- node[below, font=\small] {$\cdot a$} (h3);
  \foreach \i in {1,2,3} \draw[fwd] (x\i) -- node[right, font=\small] {$\cdot a$} (h\i);
  \draw[bwd] ([yshift=4pt]h3.north) to[bend right=35] node[above, font=\small] {$a$} ([yshift=4pt]h2.north);
  \draw[bwd] ([yshift=4pt]h2.north) to[bend right=35] node[above, font=\small] {$a$} ([yshift=4pt]h1.north);
  \draw[bwd] (h1.west) to[bend right=40] node[left, font=\small] {$a$} (x1.north west);
  \node[font=\sffamily\small, text=wrongc, anchor=west] at (10,0.9) {$\dfrac{\partial h_3}{\partial x_1} = a\cdot a\cdot a = a^3$};
\end{tikzpicture}}{Unrolled over three time steps with shared weight $a$. The
gradient travels backwards (red) and picks up one factor $a$ per step.}

\begin{steps}
\begin{enumerate}[leftmargin=*]
  \item \textbf{Unroll}: $h_1 = a x_1$, \quad $h_2 = a^2 x_1 + a x_2$, \quad
        $h_3 = a^3 x_1 + a^2 x_2 + a x_3$.
  \item \textbf{Chain rule backwards through time}:
        $\frac{\partial h_3}{\partial x_1} =
         \frac{\partial h_3}{\partial h_2}\cdot\frac{\partial h_2}{\partial h_1}\cdot
         \frac{\partial h_1}{\partial x_1} = a^3$.
  \item \textbf{Insert} $a=1$: result $1$. The values $x_2=4$, $x_3=5$ are
        distractors, because the cell is linear.
\end{enumerate}
\end{steps}

\begin{tikzpicture}
\begin{axis}[
    width=0.55\linewidth, height=5cm, ymode=log, xmin=1, xmax=10,
    xlabel={number of time steps $T$}, ylabel={gradient factor $a^T$},
    axis lines=left, samples at={1,...,10},
    tick label style={font=\scriptsize}, label style={font=\small},
    legend style={font=\sffamily\small, draw=none, at={(1.04,0.5)}, anchor=west},

  \addplot[thick, accent, mark=*, mark size=1.5pt] {1^x};
  \addplot[thick, whyc, mark=*, mark size=1.5pt] {0.5^x};
  \legend{$a=1.5$ explodes, $a=1$ stable, $a=0.5$ vanishes}
\end{axis}
\end{tikzpicture}}{The same product $a^T$ explains the vanishing and exploding
gradient problem of RNNs.}

\sub{Derivative with respect to the shared weight}

\begin{question}
Cell $h_t=a\,h_{t-1}+a\,x_t$, $a=9$, $x_1=9$, $x_2=6$, $h_0=0$. Find
$\partial h_2/\partial a$.
\end{question}
\begin{yours}
81: this is $h_1$, only one of the paths through which $a$ acts.
\end{yours}
\begin{correct}
$\partial h_2/\partial a = 2a\,x_1 + x_2 = 162+6 = 168$
\end{correct}

\fig{%
\begin{tikzpicture}[
    cell/.style={draw=accent, fill=accent!8, rounded corners=3pt, thick,
      minimum width=1.5cm, minimum height=0.9cm, font=\sffamily},
    inp/.style={font=\sffamily},
    fwd/.style={-{Latex[length=2.2mm]}, thick, black!60},
    use/.style={font=\small, text=hookc, fill=white, inner sep=1.5pt}]
  \node[inp] (h0) at (0,0) {$h_0=0$};
  \node[cell] (h1) at (3.2,0) {$h_1=81$};
  \node[cell] (h2) at (6.8,0) {$h_2$};
  \node[inp] (x1) at (3.2,-2) {$x_1=9$};
  \node[inp] (x2) at (6.8,-2) {$x_2=6$};
  \draw[fwd] (h0) -- node[use, above] {$a$ \#1} (h1);
  \draw[fwd] (h1) -- node[use, above] {$a$ \#3} (h2);
  \draw[fwd] (x1) -- node[use, right] {$a$ \#2} (h1);
  \draw[fwd] (x2) -- node[use, right] {$a$ \#4} (h2);
  \node[font=\sffamily\small, align=left, anchor=west] at (8.3,0.2)
    {$h_2 = a\,h_1 + a\,x_2$\\[2pt]
     $h_1 = a\,h_0 + a\,x_1$};
\end{tikzpicture}}{The weight $a$ is used four times. The derivative collects one
contribution from every use; the answer 81 stops after one of them.}

\begin{steps}
\begin{enumerate}[leftmargin=*]
  \item \textbf{Fast way, unroll to a closed form:}
        $h_1=a x_1$, \; $h_2=a h_1+a x_2 = a^2x_1+a x_2$.
  \item Differentiate as an ordinary polynomial in $a$:
        $\dfrac{\partial h_2}{\partial a}=2a x_1+x_2 = 2\cdot9\cdot9+6=168$.
  \item \textbf{Check with the recursive BPTT rule} (product rule, since $h_{t-1}$
        also depends on $a$):
        \[
          \frac{\partial h_t}{\partial a}
          = h_{t-1} + x_t + a\,\frac{\partial h_{t-1}}{\partial a}.
        \]
        $t=1$: $0+9+9\cdot0=9$. \quad $t=2$: $81+6+9\cdot9=168$.
\end{enumerate}
\end{steps}

\begin{center}\small
\begin{tabular}{@{}lll@{}}
  \toprule
  Asked for & Formula (this cell) & Pitfall \\
  \midrule
  $\partial h_T/\partial x_1$ (input) & $a^T$ & one path only \\
  $\partial h_2/\partial a$ (shared weight) & $2a x_1+x_2$ & sum over \emph{all} uses of $a$ \\
  \bottomrule
\end{tabular}
\end{center}

\begin{hook}
Derivative w.r.t.\ an \textbf{input}: one chain of factors. Derivative w.r.t.\ the
\textbf{shared weight}: a \textbf{sum} over every time step (product rule).
Safest: unroll to a formula in $a$, then differentiate.
\end{hook}

\topic{Generative Adversarial Networks}{}\label{sec:gan}

A GAN couples two networks through one loss. The mistake here was to treat the
generator as if it were trained separately from the discriminator; the table
also covers the related trap of reading the generator as a density estimator.

\sub{How the generator is trained}

\begin{yours}
``The computation of backpropagation for the generator is independent of the
discriminator'' was marked as true.
\end{yours}

Explicit density estimators: MLE, Parzen windows, (restricted) Boltzmann machines.

distribution'' or ``generating samples''.
\end{hook}
